# 2027 계약학과 경쟁률 실시간 모니터

진학어플라이와 유웨이의 지정 경쟁률을 실제 Chromium 브라우저로 확인하고, 5분 간격으로 GitHub Actions가 데이터를 갱신하는 무료 구성입니다.

## 감시 대상
### 진학어플라이
`계약학과 채용조건형 특별전형 경쟁률 현황`의 다음 8개 모집단위
- 헤어디자인학과-㈜준오뷰티
- 헤어디자인학과-㈜피엔제이
- 헤어디자인학과-㈜뷰티끄레아
- 헤어디자인학과-미창조㈜
- 헤어디자인학과-㈜커커
- 헤어디자인학과-㈜브이오지코리아
- 코스메틱뷰티매니지먼트학과-㈜블리비홀딩스
- 코스메틱뷰티매니지먼트학과-㈜뷰티라운지

### 유웨이
`(충남형)리안헤어뷰티아트학과 미창조(주)리안헤어`

## 사용 방법
1. GitHub에서 새 Repository를 하나 만듭니다.
2. 이 폴더의 파일과 `.github` 폴더를 모두 업로드합니다.
3. Repository → Settings → Pages → Build and deployment에서 **GitHub Actions**를 선택합니다.
4. Actions → `Update competition data` → **Run workflow**로 첫 실행합니다.
5. Pages 주소가 만들어지면 그 주소를 PC/휴대폰에서 열어 경쟁률을 확인합니다.

## 업데이트 방식
- GitHub Actions가 5분 간격으로 실제 Chromium 브라우저를 실행합니다.
- 원본 사이트가 10분 단위로 갱신하므로 5분 확인이면 충분합니다.
- 값이 바뀐 경우 `data/data.json`을 커밋합니다.
- 진학어플라이가 자동화 브라우저까지 차단하면 Actions 실행이 실패하고 `scraper-debug` 아티팩트에 화면 캡처가 남습니다.

## 주의
이 구성은 공개된 경쟁률 페이지를 자동 확인하기 위한 것입니다. 사이트의 이용약관이나 robots 정책 등 허용 범위 안에서 사용하세요.
